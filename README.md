# 💰 Expense Tracker

A simple and clean **Expense Tracker Web Application** built using **ASP.NET MVC**.
It helps users manage their income and expenses with filtering, sorting, and real-time balance tracking.

---

## 🚀 Features

* ➕ Add, Edit, Delete transactions
* 📊 Dashboard with:

  * Total Income
  * Total Expense
  * Balance
* 🔍 Filter transactions by:

  * Type (Income/Expense)
  * Category
  * Date range
* 📅 Date validation (no future date, proper range check)
* 🔃 Sorting by date
* 🔎 Search functionality
* 🧹 Clean and responsive UI

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** ASP.NET MVC (C#)
* **Database:** SQL Server
* **ORM:** Entity Framework

---
## ⚙️ How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/Expense-Tracker.git
```

2. Open project in Visual Studio

3. Configure database connection in `appsettings.json`

4. Run migrations (if needed)

```bash
Update-Database
```

5. Press **F5** or click **Run**
